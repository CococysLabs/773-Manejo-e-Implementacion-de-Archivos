# Laboratorio MIA_B_2S2026

## Descripción

Este programa está desarrollado en **C++** y tiene como objetivo practicar la entrada y salida de datos por consola, así como el manejo de variables de tipo `string` y `char`.

Al iniciar, el programa muestra un mensaje de bienvenida al Laboratorio MIA_B_2S2026. Posteriormente, solicita al usuario ingresar un texto completo y un carácter individual, mostrando en pantalla los datos ingresados.

## Funcionalidades

- **Mensaje de bienvenida:** muestra un mensaje al iniciar la ejecución.
- **Ingreso de texto:** solicita una cadena de texto al usuario mediante `getline()`, permitiendo ingresar espacios.
- **Visualización de texto:** imprime la cadena ingresada en la consola.
- **Ingreso de un carácter:** solicita un único carácter utilizando `cin`.
- **Visualización de carácter:** muestra el carácter ingresado por el usuario.

## Tecnologías utilizadas

- **Lenguaje:** C++
- **Biblioteca:** `iostream` para entrada y salida de datos.
- **Biblioteca:** `string` para el manejo de cadenas de texto.

## Ejecución

1. Compilar el archivo fuente utilizando un compilador de C++.
2. Ejecutar el programa generado.
3. Ingresar el texto solicitado.
4. Ingresar un carácter individual.
5. Visualizar los datos ingresados en la consola.

### Ejemplo de ejecución

```text
Bienvenidos al Laboratorio MIA_B_2S2026
Ingrese un texto: Hola mundo
El texto ingresado es: Hola mundo
Ingrese un caracter: A
El caracter ingresado es: A
```

## Objetivo

Practicar los conceptos básicos de programación en C++, incluyendo la declaración de variables, la lectura de datos desde la entrada estándar y la impresión de resultados mediante la consola.
